## 1. 必须先说清的前提：双极性编码器不产生脉冲

`third_party/neurocardio/neurocardio/sarhaddi.py:50`：

```python
def dual_polarity_encode(x, eps=1e-5):
    z = (x - x.mean(-1, keepdim=True)) / x.std(-1, keepdim=True).clamp_min(eps)
    return torch.cat([F.relu(z), F.relu(-z)], dim=1)
```

返回值是**连续非负数**，`NeuroCardio` 直接把它喂给 `stem_conv`，中间没有任何阈值化。实测统计（十折训练子集）：

| 量 | 值 |
|---|---|
| 最小值 | 0.0 |
| 最大值 | **20.91** |
| 均值 | 0.2997 |
| 精确为 0 的元素占比 | **50.00%** |

50% 恰好为 0 是因为正负两半中必有一半被 ReLU 截断；另一半是连续值，可以取到 20.9。**它既不是 0/1，也不是任何意义上的脉冲串。**

由此有两个必须记住的后果：

1. **`ab_polarity` / `ab_shallow_pol` 是"模拟前端 + 脉冲主干"的混合网络**，第一层 `stem_conv` 是稠密卷积。论文里不能写成"双极性**脉冲**编码"。
2. **不能拿它和二进制 delta 比保真度**。模拟量当然比二值量保真，这是构造性的，不是发现。任务书原本的 P0-2 若照此执行，得到的必然是"双极性更好"，且该结论毫无信息量。

因此本报告把比较搬到**同一脉冲预算**上。

## 2. 三种臂

| 臂 | 说明 | 是否脉冲 |
|---|---|---|
| `delta_th{0.10,0.15,0.20,0.30}` | 原始 delta 编码器，θ 扫描 | 是（二值） |
| `bipolar_bin_tau{0.5,1.0,2.0}` | 双极性张量按固定阈值二值化 | 是（二值） |
| `bipolar_bin_countmatched` | 双极性**逐样本**选阈值，使该样本的脉冲数与 delta(θ=0.15) **完全相同** | 是（二值） |
| `bipolar_analog` | 部署中的双极性编码器，仅作上界参考 | **否** |

`countmatched` 是唯一真正"同预算、不同编码方案"的对照。阈值取该样本 |z| 的第 k 大值（k = 该样本自身的 delta 脉冲数）：阈值**逐样本独立确定**，不触碰标签，也不使用测试折的任何聚合统计或拟合量。它是"每样本给定预算"的约束，不是一个在测试折上调出来的超参数。

## 3. 可解码性协议

| 项 | 设置 |

## 5. 三条读得出来的结论

**一、保真度差异不是"脉冲更多"造成的。** 把双极性二值化到与 delta 完全相同的脉冲数（8,083 vs 8,088），可解码性高 **7.6–7.7 pp，10/10 折全胜**。任务书想分离的两件事，在这里被分离开了。

**二、delta 的脉冲分配是低效的。** delta 自己越稀疏越好：θ 从 0.10 加到 0.30，脉冲从 9,238 降到 5,689，可解码性反而从 0.5543 升到 0.6014。即它"多发出去的那 62% 脉冲"对线性可解码性没有贡献，甚至是噪声。

**三、双极性用 1/3.3 的脉冲就超过 delta 的最优点。** τ=1.0 在 1,716 脉冲下拿到 0.6862（bin20），比 delta 的最优 θ=0.30（0.6014，5,689 脉冲）高 **8.5 pp**。

**四、把双极性二值化不损失可解码性，反而更高。** 模拟臂 0.6362 < 预算对齐臂 0.6492 < τ=1.0 臂 0.6862。也就是说：**"去掉二值化"本身不是精度来源**，编码方案的形状（对每个导联做局部 z-score 后取正负两路）才是。这一点对论文很关键——它说明改用双极性编码的收益可以归因于编码方案，而不是"偷偷放宽了脉冲约束"。

## 6. 结论（约 200 字）

在同一脉冲预算下（8,083 vs 8,088 脉冲/样本），双极性二值编码的线性可解码性比压摆率受限的 delta 编码高 7.6–7.7 pp（10/10 折，p≈4e-8）；双极性仅用 1,716 脉冲即超过 delta 在 5,689 脉冲下的最优点 8.5 pp。delta 自身表现为"脉冲越多越差"，说明其额外事件对线性可解码性无贡献。模拟双极性张量并不优于其二值化版本，因此差异来自编码方案而非量化精度。本结果只涉及线性可解码性、单一数据集、seed 0；不能据此断言下游非线性模型一定获益。

## 7. 局限与未计算项

- `bipolar_analog` 的"脉冲/样本"一列填的是**非零元素数**，不是脉冲数，必须在表注中说明。
