# P0-3 深层"空转"剖图（机制 B）

- 日期：2026-10-26
- 脚本：`experiments/36_p0_spike_profile.py`（推理）、`experiments/38_p0_report.py`（汇总作图）
- 数据：`results/p0_spike_profile_{ab_full,ab_polarity,ab_shallow,ab_shallow_pol}.json`
- 图：`results/fig_p0_depth.png`
- **不使用任何新训练**，全部读取既有 seed 0 checkpoint

## 1. 问题

DR-BSN 的叙事假设：深层的脉冲发放率塌到接近 0，所以"加深不能转化为容量"，减深度才划算。

这个假设需要一个可测的量。本报告同时测两个：

- **发放率 ρ**：块输出在时间池化**之前**的脉冲均值。回答"这一层还在不在发脉冲"。
- **有效秩 r_eff**：池化前脉冲图的通道协方差参与率。回答"这一层实际用到了几个通道方向"。

两者可以脱钩：一层可以持续发放，却始终只用少数几个通道 → ρ 正常、r_eff 塌陷。这正是本报告发现的情形。

## 2. 有效秩的定义（逐字）

对一批数据的池化前脉冲图 S ∈ R^{B×C×T}，把 N = B·T 个通道活动向量当作观测、C 个通道当作特征：

```
X   ∈ R^{C×N},   μ = mean over N
Cov = (X − μ)(X − μ)ᵀ / N            ∈ R^{C×C}
PR  = (Σᵢ λᵢ)² / Σᵢ λᵢ²              （参与率，participation ratio）
r_eff = PR / C                        ∈ (0, 1]
```

协方差在整个 split 上累加，不是逐 batch 计算。只用到 k 个通道的层，其 r_eff ≈ k/C，与平均发放率大小无关。

## 3. 协议

| 项 | 设置 |
|---|---|
| 权重 | 既有 seed 0 十折 `best.pt`（EMA 权重） |
| 测试 | 第 f 折全部样本 |
| 验证 | 第 f−1 折全部样本（f=1 时取第 10 折） |
| 训练 | 其余 8 折中固定随机抽 2000 条（seed 0） |
| batch | 64 |
| 配置 | `ab_full` / `ab_polarity`（6 块）、`ab_shallow` / `ab_shallow_pol`（3 块） |

> 注：`ab_polarity` 的编码器输出不是脉冲（见 `p0_encoding_fidelity.md` §1），但其**各块的输出确实是 `lif2` 发放的 0/1 脉冲**，所以块级 ρ 在其上是有效量。

## 4. 结果一：逐层发放率与有效秩（十折均值，测试折）

| 配置 | 块数 | 参数 | L1 ρ / r_eff | L2 | L3 | L4 | L5 | L6 |
|---|---|---|---|---|---|---|---|---|
| 6 块 · delta | 6 | 1,893,768 | 0.1117 / 0.4312 | 0.1288 / 0.1532 | 0.1634 / 0.1507 | 0.0972 / 0.0408 | 0.1080 / 0.0203 | **0.0551 / 0.0062** |
| 6 块 · 双极性 | 6 | 1,893,768 | 0.1338 / 0.4297 | 0.1509 / 0.1543 | 0.1775 / 0.1917 | 0.1104 / 0.0661 | 0.1204 / 0.0419 | **0.0527 / 0.0068** |
| 3 块 · delta | 3 | 528,392 | 0.1166 / 0.4772 | 0.0933 / 0.2109 | 0.0532 / 0.0480 | — | — | — |
| 3 块 · 双极性 | 3 | 528,392 | 0.1388 / 0.3941 | 0.1089 / 0.1724 | 0.0552 / 0.0573 | — | — | — |

（十折标准差见 `p0_aggregate.json`；图上为 ±1 sd 带。）

**读法：**

1. **ρ 不单调**。6 块 delta：0.112 → 0.129 → 0.163 → 0.097 → 0.108 → 0.055。L3 是峰值，之后掉一半，L5 又回升。所以"逐层递减"的写法**不成立**，必须写成"L3 之后整体下移"。
2. **r_eff 单调塌陷**。6 块 delta：0.431 → 0.153 → 0.151 → 0.041 → 0.020 → **0.0062**。L6 只用到 384 个通道里的约 2.4 个等效方向。
3. **换编码器不改变塌陷的形态**。双极性下 L6 是 0.0068，delta 下是 0.0062。ρ 的绝对水平整体上移（L4 0.110 vs 0.097），但"L1 → L2 掉 3 倍、L5 → L6 再掉 7 倍"的结构一致。
4. **塌陷从 L2 就开始了**，不是"只有最后几层死"。

## 5. 结果二：这不是过拟合

三个 split 的剖面几乎逐位相同：

| 配置 | split | L6 ρ | L6 r_eff |
|---|---|---|---|
| 6 块 delta | 训练（2000 条） | 0.0559 | 0.0060 |
| 6 块 delta | 验证 | 0.0549 | 0.0062 |
| 6 块 delta | 测试 | 0.0551 | 0.0062 |

同时训练损失在下降：`ab_full` 1.0965 → 0.4269（100 epoch 均值，首轮 → 末轮）。

⇒ **深层在训练集上同样只用 0.6% 的通道容量**。网络确实在拟合（损失降 61%），但新增的深度没有在训练集上被用起来。这与"过拟合导致泛化差"是两回事，属于**结构性空转**。

## 7. 结论（约 200 字）

在 PTB-XL 官方十折、seed 0 的既有权重上，脉冲卷积栈的**发放率随深度非单调**（先升到 L3，之后下移但不趋零：末层仍有 0.053–0.055），而**有效秩单调塌陷**：池化前脉冲图实际占用的通道方向从约 43% 降到 0.6%。塌陷在训练集、验证集、测试集上几乎一致，训练损失同步从 1.10 降到 0.43，因此这是结构性空转而非过拟合。换用双极性编码只把发放率整体抬高，不改变塌陷形态。结论是：**"深层失效"的真实指标是表示秩，不是发放率**；任务书原设的"发放率塌到 0"在本数据上不成立，应改写。本结果只覆盖一个数据集、一个种子。

## 8. 反直觉 / 负面结果

- 发放率非单调，末层仍发脉冲。**"脉冲消失"这一措辞不能再用。**
- 塌陷在 L2 就很明显（r_eff 从 0.43 掉到 0.15），"只有最后几层"的说法不成立。
- 3 块的末层 r_eff 只有 0.048–0.057，同样很低 —— 说明减深度并没有消除空转，只是少了几层空转。

## 9. 局限

- 单一数据集（PTB-XL）、单一种子（0）、一种统计口径。
- 有效秩只刻画线性相关性，非线性可利用的容量未测（未计算）。
- 未做线性探针（任务书列为可选，本次未计算）。
- 训练 split 只抽 2000 条，不是全量 17,091 条。
