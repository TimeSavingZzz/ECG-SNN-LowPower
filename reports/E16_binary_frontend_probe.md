# E16 二值化前端零样本探针：现在这套「SNN」的输入其实不是 spike

> 产物：`results/bin_probe_ab_shallow_pol.json`（md5 `fe02bbfd`）、
> `results/bin_probe_ab_polarity.json`（md5 `d6c56466`）
> 脚本：`experiments/53_binary_frontend_probe.py`
> 本文件只陈述事实，不决定论文怎么写。

---

## 0 动机

`ab_polarity` / `ab_shallow_pol` 的前端是 Sarhaddi 的双极性**连续**整流编码：

```
z = (x − mean_t) / std_t          # 逐导联逐样本 z-score
enc = concat( ReLU(z), ReLU(−z) )  # 24 通道，连续值
```

输出**不是 0/1**，`ReLU(z)` 可以是 0.3、1.7、4.2……因此：

- 严格说这两个配置的输入是**模拟量**，不是脉冲列；
- stem conv 是稠密卷积，`cost_snn` 对 stem 的计费必须按 E9 的方式修正（3 块 +40.0%，6 块 +16.7%）；
- 前端「θ 无关」不是优点，是因为**θ 在这里根本没有位置**。

本探针把前端换成真正的二值形式（θ 以 z 为单位）：

```
spike⁺ = 1[z ≥ θ],  spike⁻ = 1[z ≤ −θ]
```

**不重训、不改权重**，只量「零样本换成二值后会掉多少」。
这是重训是否值得的下界探针，**不是**重训后的上限。

## 1 结果

`ab_shallow_pol`（3 块，528 392 参数）：

| 前端 | fold9 AUROC | fold10 AUROC | 输入发放率 |
|---|---|---|---|
| 连续整流（原样） | **0.8795** | **0.8791** | 0.313 / 0.311 |
| 二值 θ=0.15 | 0.6788 | 0.6650 | 0.405 / 0.403 |
| 二值 θ=0.5 | 0.7143 | 0.7646 | 0.208 / 0.204 |
| 二值 θ=1.0 | 0.5795 | 0.6363 | 0.079 / 0.077 |
| 二值 θ=1.5 | 0.4921 | 0.5739 | 0.037 / 0.037 |
| 二值 θ=2.0 | 0.4760 | 0.5434 | 0.022 / 0.023 |

`ab_polarity`（6 块，1 893 768 参数）：

|---|---|---|---|
| 连续整流（原样） | **0.8689** | **0.8716** | 0.313 / 0.311 |

## 2 读数

1. **掉得很凶**：最好的零样本二值点（θ=0.5）比连续前端低 **11.5 pp**（3 块 fold10：0.7646 vs 0.8791）、
   **15.4 pp**（6 块 fold10：0.7174 vs 0.8716）。最差点（θ=1.5–2.0）已接近随机（AUROC 0.48–0.58）。
2. **不是「几乎等价于二值」**：若连续整流本身近似二值，二值化应当几乎无损。实际掉 10–35 pp，
   说明**幅度信息承担了实质工作**——网络确实在用 `ReLU(z)` 的数值大小，而不只是符号。
3. **θ 越大越差**，但**不是因为信息少**：θ=1.0 时发放率只剩 0.077，输入仍保留符号结构，
   精度却掉到 0.58–0.66。也就是说，训练分布是在连续输入上形成的，
   零样本换分布**不能**用来判断二值编码的信息上限。
4. **SOP 不降反升是假象**：二值输入下 `cost_snn` 对 stem 的计费是正确的（输入是真 0/1），
   但深层发放率被扰乱，总 SOP 反而在 6 块上从 49.1 M 涨到 40.6–45.0 M（无单调关系）。
   这一列**不能**当作「二值化省能耗」的证据。

## 3 这份探针**不能**回答什么

- **不能**说明重训后的可达精度。前端换成一个固定非线性、再从头训练，恢复多少是未知的。
- 零样本点之间不是同一模型的不同工作点，只是把同一个权重喂不同输入分布，因此
  **不能**画成「精度–能耗帕累托前沿」。
- 只测了 fold9 / fold10 两个折、两个配置。

## 4 为回答「重训能否补回来」而起的实验（试点，进行中）

- 新增模型：`NeuroCardioShallowPolarityBinary`（3 块 + 二值双极性前端，θ 由 `theta_bin` 绑定），
  工厂名 `ab_shallow_pol_bin{θ×100}`，例如 `ab_shallow_pol_bin050`。
- 试点：fold10，100 epoch，batch 96，θ_bin ∈ {0.30, 0.50, 1.00, 1.50}，4 卡并行，
  约 11.5 h（单 epoch ≈ 416 s，与既有十折同配方）。
- 判据（事先写死，避免事后挑数）：
  - 任一 θ 的 fold10 测试 AUROC ≥ **0.87**（即与连续前端 0.8791 差距 ≤ 1 pp）⇒ 二值化可行，值得铺十折；
  - 最好点落在 **0.84–0.87** ⇒ 可行但有明确代价，需要按「精度换能耗」叙事；
  - 最好点 **< 0.84** ⇒ 二值前端这条路在现配方下不成立。
- 试点只用 fold10，**不进**任何显著性统计；结论只作下一步决策依据。
